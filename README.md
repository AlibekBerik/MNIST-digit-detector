# MNIST-digit-detector
This project builds a simple neural network that can recognize handwritten digits (0-9) using **TensorFlow** and **Keras**. The model is trained on the MNIST dataset and can achieve around **97% accuracy** on test data.

## Features
- Fully connected neural network (Dense layers)
- Normalizes pixel values for faster learning
- Trains on MNIST dataset (28x28 grayscale images)
- Evaluates test accuracy
- Predicts digits from individual images
- Visualizes the input image with matplotlib
